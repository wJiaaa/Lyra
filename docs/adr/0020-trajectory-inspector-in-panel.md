# ADR-0020：轨迹时间轴和详情留在面板内

- 状态：已采纳
- 日期：2026-09-07
- 相关：`features/conversation/trajectory`、`e2e/trajectory.test.ts`

## 背景

时间轴和详情原先各自弹出浮层，查看下一条记录需要反复开关，缩放控件随弹层位置变化。
Plume 的停靠面板可独立缩放，整窗宽度不能代表详情实际能使用的空间。

## 决定

时间轴固定在工具栏下，缩放控件始终占位，时间区间选择只强调记录而不改变账本行数。
保留实际时间比例、Canvas、增量 IPC 与虚拟列表。参考 deepseek-harness 的本地 inspector
及时间聚焦语义，沿用 Plume 数据契约、图标、色彩和停靠行为。

面板至少 720px 时详情与账本并排；更窄时详情覆盖账本区域，保留账本 DOM 和滚动位置。
详情头部固定返回、上一条、下一条和更多操作，内容、信息、原始内容各有标签。
窄矮停靠区优先保留记录，放大面板后恢复时间轴。

## 后果

查看记录不需要另一层浮窗，不再因弹窗自动定位而移动时间轴按钮。需要同时保留两个
滚动区域的状态，并在真实窗口验证容器断点、范围拖选和焦点返回，而非只测组件挂载。
模型错误、浏览器空态、智能体定义编辑继续复用各自原有功能域，不引入第二套壳层。
