# ADR-0045：持续目标——每轮收尾由独立裁判判「做到没有」，没做到就续，要等就退避

日期：2026-10-11

状态：已采纳。对 ADR-0033「不把运行时做成可续跑的任务」是一处明确的例外：续不续由人开启的目标
和一个独立裁判决定，不是运行时自己猜。

## 背景

Plume 的一轮在模型说「停」的时候就停。人要的往往不是一轮，是一个结果：「CI 变绿」「这个 PR 合进去」
「每天九点把昨天的失败测试修掉」。现在只能人盯着，每次回来再说一句「继续」；定时任务（`scheduler.ts`）
每次开一个新会话，上一次读过的东西全部重读。

maka、dsh、ZCode 都有这个东西：人给目标，每轮结束由一次独立的判定决定达成、不可能、有进展、在等待；
等待时退避，不空转。它和 AGENTS.md「别让循环替人做决定」不冲突：开不开由人决定，裁判判的是
「做完没有」，不是「卡住没有」——后者没有可靠信号（`agent/repetition.ts` 顶上那段教训），前者有：
目标在那里写着，最后一句回复在那里写着。

## 决定

**状态全在 `SessionMeta.goal`**（`types/goal.ts`），每次变化落盘。进程死掉再起来，等着的目标按
`wakeAt` 接着等（`SessionGoal.arm`），跑到一半的留在原状态、下一轮收尾再判。没有另一张表、另一个文件。

**裁判是一次不带工具的小请求**（`runtime/goal-judge.ts`）。它看目标、清单、这一轮调了哪些工具、
最后一句回复——几千 token，不是整段历史。答五种之一：

| 结论 | 下一步 |
| --- | --- |
| `met` | 终态，通知 |
| `impossible` | 终态，通知；理由是裁判写给人的「缺什么」 |
| `progress` | 立刻以运行时的名义（`synthetic`）开一轮：「还没到，{理由}，接着做」 |
| `stuck` | 同上，措辞是「换个办法」；连着 5 次停下 |
| `waiting` | 睡 30s → 1m → 2m → 5m → 10m → 30m 封顶；有进展就从头数；醒来那一轮说清在等什么 |

读不出结论算「这次没判成」：既不是到了也不是卡了，接着跑；连着 3 次停下。裁判的用量照记
（`usage` 记录，`source: "goal-judge"`），模型按设置页 `goal` 那一行选，没选跟会话。

**三条硬线**，撞上哪条都停下来等人（`paused`，带原因）：最多判 50 次、连着 5 次没进展、
连着 3 次读不出结论。人按停止、这一轮报错或撞上步数/重复上限，同样停——那是循环已经替人停下的
场合，目标不越过它自己续。

人按停止时目标**当场**停，不管它在做、在判还是在等；不等那一轮以 `aborted` 收尾再停——那一轮可能
已经 `done` 收尾、正等会话闲下来，这时再没有 `aborted` 会来。推进路上（等空闲、问裁判、落盘、开下
一轮）每个 await 回来都对一次人的操作计数，人动过手就作废这次推进。会话为让人插话、编辑重发而停下
的那一轮不算停止：那是人开口，那一轮收尾时照常判；会话收摊（退出、处置）也不算，等着的目标原样留在
磁盘上。

服务商报错以「这一轮最终失败」为准：重试中的抖动不进 `agent_end`，重试用完或不可重试的错误才让这一轮
以 `error` 收尾，目标随之停下。

**它排在所有人后面。** 只在 `agent_end` 为 `done` 且会话真闲下来（`whenIdle`：排着的任务、攒着的
后台结果都走完）之后才判。人在睡着的期间开了口，醒来那一下让路，那一轮收尾时再判。

**提示词多一段**（`PromptSource` 的 `goal`）：有目标、每轮收尾有人检查、要等外面的事就说清在等
什么然后停。目标那句话以人的名义进对话（它是人说的）；之后的续跑是 `synthetic` 的用户消息，转录
里不替人说话。

## 不做的

- **不让裁判看整段历史。** 判「做完没有」要的是目标和最后的状态，一次几十万 token 的裁判比它要
  判的那一轮还贵。
- **不自动续被按停的。** 停止就是停止。
- **不把定时任务改成目标。** 定时任务是「到点新开一个会话」，目标是「这个会话跑到做完」。一个会话
  可以两者都有：定时任务开出来的会话里 `/goal`，就是「到点开始、做完为止」。
- **不在对话里念账单。** 判了几次、还剩几次在状态条上；通知只在终态发。

## 后果

- 等着的目标占一个活会话名额（`session-hub.ts` 的 `sessionBusy`），不被回收。
- 目标进行中那一轮轮的「完成」系统通知不发，终态才发（`notify.ts`）。
- 裁判会错。错成「到了」是最贵的一种：人以为做完了。所以提示词里写死「回复里能看出来，不是嘴上说」。
  真实会话上量过之后再调。
