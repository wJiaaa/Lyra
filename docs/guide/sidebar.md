# 侧边栏排序

侧边栏只有一张列表：项目在上，「最近」显示全部可列出的会话，包含项目内、无项目和置顶会话。项目与置顶分组仍保留入口，同一会话在「最近」中只显示一次。搜索时换成按日期分段的全部匹配。
已归档的会话不在侧边栏里，到 设置 › 已归档的聊天 查看。
尚未开始的空会话不列出，当前正在开始的会话除外。「最近」默认显示 5 条，可通过「展开显示」继续查看。

在项目列表中，用鼠标拖动项目名称可调整同一区域的项目顺序；置顶项目与普通项目分别排序。
拖动项目内的会话可以调整该项目的会话顺序，并切换到「手动排序」。打开项目、切换会话或重启后保留排序。

「列表设置」在「项目」标题右侧，和「新建项目」一起，鼠标移入标题时显示；没有项目时在「最近」标题右侧。
它可以切回最近更新或最近创建，再选「手动排序」恢复之前的位置。新的会话显示在手动列表顶部。
搜索结果、单独置顶的会话和「最近」里的会话仍按时间排列；「最近」跟随最近创建或最近更新的选择，手动排序时按最近更新排列。拖动「最近」里的会话不会改写项目内顺序。触屏保持原生滚动，「列表设置」常显。

拖动中按 Escape、失焦或收到系统取消事件都会取消移动，不修改保存的顺序。松开后只排序，不打开会话或折叠项目。
