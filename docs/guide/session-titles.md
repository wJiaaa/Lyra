# 会话标题

新会话先显示首条消息的简短标题。智能标题默认开启，正文超过 12 个 Unicode 字符时，后台额外
请求一次模型生成标题。优先使用 `@fast`，未配置时使用当前会话模型。设置中的「智能标题总结」
可关闭这项请求。

标题只读取用户可见正文（`displayText` 优先），不根据普通文字中的「使用」「技能」或引用提示
标签删除句子。仅引用技能或历史会话时，直接发送和恢复待发送消息都使用引用名称；
仅图片消息沿用「图片消息」标题。

标题请求最多读取开头 4000 个 Unicode 字符，并按所选模型的窗口进一步缩减；输出最多 60 tokens，
15 秒超时。失败时保留初始标题。已返回的辅助请求用量作为独立 `usage` 记录计入会话总用量，
不会成为对话消息；冷恢复和编辑消息不会抹掉这笔已产生的用量。
取消发生在模型已经返回结果或终态事件之后时，仍记录其中的真实用量；没有收到终态用量则
不估算，也不追记取消后才到达的结果。

手动改名、停止、重编辑、关闭智能标题和销毁会话会取消后台请求。改名、重编辑及销毁会先等待
已经开始的标题写盘结束，旧请求不能在新标题或会话删除后再写回。

手动改名在标题记录中标记归属。存储队列会拒绝覆盖手动名称的自动标题，
过期的模型或设置元数据也不能恢复旧名称。
