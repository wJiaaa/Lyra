# 生成图片

对话里说「画一张……」「把这张图改成……」，模型会调用 `image_generate`，用你配置的生图模型把图画出来，
直接显示在对话里。一个生图模型都没配时，模型手里没有这个工具。

## 加一个生图模型

设置 → 模型设置 → 选供应商 → 添加模型，填模型 ID，例如：

- `gpt-image-1`、`dall-e-3`（OpenAI 及兼容的中转）
- `gemini-3.1-flash-image`、`gemini-2.5-flash-image`、`gemini-3-pro-image-preview`
- `imagen-4.0-generate-001`、`flux-1.1-pro`、`doubao-seedream-4-0`

名字认得出的会自动打开模型编辑器里的「生图模型」开关；自家起的名字（比如 `house-artist`）自己打开就行。
打开后，上下文窗口、思考、工具调用这几项不再显示——它们对画图没有意义。

生图模型不会出现在对话模型的列表里，对话模型也不会出现在生图模型的列表里。

「拉取模型」能列出生图模型的中转，勾上就加进来了。很多中转的 `/v1/models` 只列聊天模型，这时在拉取弹窗的
搜索框里敲模型 ID、按回车，一样能加。同一个弹窗里取消勾选已有的模型就是移除，点「应用」才会保存。

在模型列表里，生图模型那一行的测试按钮会真画一张小图（会计费），能用就显示画出来的大小。

## 用哪一个

有一个就用那一个。有好几个时，在 设置 → 智能体 → 会话 → 生图模型 里选默认的，或者在供应商的模型列表里
点「设为默认生图模型」；不选就是第一个。对话里点名也行：「用 dall-e-3 画」。点的名字对不上、或者对上不止
一个时，模型会被告知现有哪几个，不会悄悄换成默认的那个。

## 比例、画质、张数

说「16:9 的横幅」「竖版」「高清」「来四张」就行，模型会把它换成工具参数：比例（`1:1`、`16:9`、`9:16` 等十种）、
画质（`low` 到 `max`，`max` 是模型能给的最大尺寸，Gemini 上是 4K，慢也贵）、一次 1 到 4 张、透明背景。
各家的写法不一样——gpt-image 要 `1536x1024` 这样的像素尺寸，Gemini 中转要 `aspect_ratio` 和 `image_size`——
这层翻译在 Plume 里做，不用在模型编辑器里填。几张里有的没画出来时，画出来的照常显示，模型会被告知少了几张。

## 走哪个接口

先走 Images API（`/v1/images/generations`，改图走 `/v1/images/edits`）；供应商回答「没有这个接口」时，改用
对话接口（`/v1/chat/completions`，要求输出图片）再试一次，并记住这个模型走哪条路，下次直接走对的那条。
OpenRouter 只有对话接口，直接从那条走。

每张图最多试 3 次。额度用完（比如「quota will reset after 1h52m」）不重试，模型会告诉你大概多久之后重置；
key 没有这个模型的权限时也不重试。这两种情况对话里会出一张卡片，直接写是哪个模型、多久恢复或该去哪里开权限。

## 画的时候

图先按要的比例占好位置（没说比例的改图按原图的比例），图上一行写进行到哪一步，角上是估计的进度——接口不报进度，
这个数是按这类模型通常要多久估的，不会自己走到 100%，图到了才算完。重试时那一行写「连接不稳，正在重试」。
图到了在原地从模糊变清晰，框不变大小；那一行换成模型和尺寸，少了几张也写上。

## 改图

把图贴进输入框，说要改什么；本地文件给路径也行。对话里画出来的图右键有「添加到聊天」，加进输入框后接着说要怎么改。
鼠标移到画出来的图上有「编辑」和下载：「编辑」直接进标注，圈出要改的地方后按「完成」，带标注的图放进这个对话的
输入框，接着说「照这个改」就行。点开大图后的「标注」也一样。
也可以直接说「把上一张改成夜景」：对话里的图从新到旧编号（`#1` 是最新的一张，贴进来的、画出来的、截图都算），
模型按编号取，一次最多 8 张。

## 画廊

侧栏「插件」下面是「画廊」：所有对话里画过的图按天排在一起，宽图按原比例排，不裁成方块。卡片左上角
的数字是这张图所在的那条链一共几步，悬停能看到当时说的那句话。顶上的搜索框按说过的话、提示词和对话名找。

点开一张：

- 右边是它的生成链路：从第一张起，一步步改到现在的样子，每一步写的是你当时说的话。同一张图往两个方向
  改过，另一条分支整段列在后面，左边一条括线接回它是从哪张分出来的；这张图自己的来路用蓝色标出。旧对话
  没记下每次改的是哪张，按当时的 `#1`、`#2` 倒推出来。
- 「在对话中查看」打开那个对话，滚到画出这张图的地方，图框闪一下。
- 图下面的输入框写一句要怎么改，回车就发到这张图所在的对话，图一起带过去；画好以后回到画廊，直接停在
  新图上。左边的笔可以先在图上圈出要改的地方，圈过的那一步也会出现在链路里。
- ← → 换上一张、下一张，Esc 关闭，点大图可以放大。

手机上没有画廊；子智能体画的图不进画廊。

画出来的图存在 `~/.plume/session-media/`。画廊与链路的设计取舍见 [ADR-0047](../adr/0047-gallery-and-lineage.md)。
