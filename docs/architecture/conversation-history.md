# 会话历史边界

会话日志保存原始转录。Anthropic Messages、OpenAI Responses 和 Chat Completions 的请求在
发送前统一整理工具配对：每个调用只使用紧随该 assistant 的结果组中的首个匹配结果，缺失结果
标为执行中断，孤儿和重复结果不进入请求。跨轮重复的调用 id 分别配对，不借用后续轮次的结果。
整理过程不改写磁盘转录。

编辑重发先停止当前请求，再等待消息接收、写盘、执行和后续队列处理的完整生命周期结束后截断。
仅等待模型执行不足以保证安全：初始用户消息还在异步接收时，同样拥有这段历史。

截断以当前有效消息的日志 seq 为准，不能重新按物理消息行计数。旧 truncate 记录留下的历史行
不属于当前索引；截到 toolResult 时，边界退回该组 assistant 之前，保证调用及其结果一并移除。
非整数和越界索引不能改变日志。截到压缩边界本身（第一条保留消息）时，边界保留；截到它之前才作废。

闲置时撤回或编辑重发，派发已被截掉的后台子代理随即停止，其结果不再送回；派发仍在保留历史里的继续运行、照常送达。
回合进行中的编辑重发先整体停止，所有子代理一并停下。

日志末行在崩溃时只写了一半的，下一条记录另起一行写入，不与半行拼在一起；读取时半行照旧跳过。
