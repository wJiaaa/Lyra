# 工作区工具与交付记录

## 浏览器

桌面主进程的 `browser-workspace.ts` 持有标签注册表；渲染进程只显示注册表对应的 sandboxed
`webview`。用户和 Agent 操作同一页面，Agent 不再另开用户看不到的窗口。标签使用 UUID，
最多 20 个，切换标签与关闭面板保留 DOM、表单、历史和页面脚本；关闭标签或明确释放会话才销毁。
有浏览器标签或仍运行后台任务的会话不会被普通空闲淘汰回收。

标签归会话所有，面板只画当前会话的那一组，「当前标签」也按会话记（`activeBySession`），
Agent 打开页面时复用的是它自己会话的标签，不会写到用户正在看的那一个上。**页面比标签少**：
一个 `<webview>` 是一个渲染进程，所以只有最近三个会话的页面保持挂载，更早的会话卸载页面、
保留标签，切回时按标签记录的地址重新加载。两条例外保证它不会卸到正在用的页面上——会话里有
turn 在跑时它的页面始终挂载，主进程通过 `awakeBrowser` 标记 `wanted` 可以随时要回一张已经
睡掉的页面（Agent 的每个 `browser_*` 调用都先经过它）。`reveal` 只对当前会话生效，后台会话
开页面不会把面板推到用户面前。

「面板就绪」和「页面加载完」是两件事。`<webview>` 一挂上（`did-attach`）就向主进程报到，不等站点
回第一个响应——从前等 `dom-ready`，站点 30 秒不回，开页就报「浏览器面板没有在 30 秒内就绪」。
Agent 要读、要点的是文档，`loadedBrowser` 在每个 `browser_*` 调用前等文档就绪，最多 30 秒，超时
报「页面没有加载出来」，标签留着。

页面在 Agent 调用期间弹出的 alert、confirm、离开页面提示由 `browser-dialogs.ts` 应答：alert 确定，
confirm 与离开提示默认取消、调用带 `dialog: "accept"` 才确认，结果附在工具结果末尾。两次调用之间弹出
的照旧是系统对话框，下一次调用开始时收起它并代为应答。人自己浏览时不接管。分岔点在 Electron 自己弹
系统对话框的 `-run-dialog` 监听上，而不是 CDP：CDP 应答后那个系统对话框仍留在窗口上。

`read` 给每个可操作元素一个 ref（`e12`），记在隔离 world 里，编号按标签接续、换文档也不从头编，
旧页的 ref 只会报失效、不会点到新页的别的元素。点击、悬停、输入前 `browser-locate.ts` 确认元素可见、
未禁用、位置稳定、落点没被遮挡，最多等 3 秒，否则报出是哪一条。`wait` 在主进程里逐轮问页面，跨跳转也成立。

页面没加载出来、或页面进程停了，写进 `BrowserTab.failure`，面板在页面区域上盖一层原因和「重新加载」，
不插在页面上方——插一行字会把页面挤矮，而对已崩溃的 guest 调设备仿真会让主进程段错误、整个应用退出
（Electron 44.7 实测，`applyView` 因此跳过崩溃的页面）。页面进程第一次没了自动重新加载，15 秒内再没了就停在
盖层上等人；agent 的调用此时直接报错，`reload` 照人点刷新处理。`browser_open` 打不开站点时报出原因，不交回空的错误页。

`browser_open`、`browser_tabs`、`browser_act`、`browser_viewport`、`browser_screenshot`
由当前可信运行上下文取得 sessionId，不能指定其他会话来绕过所有权。浏览器 IPC 仅接受主窗口
的主 frame；guest 必须确实归属于发送 attach 的窗口。主进程同时校验 URL、命令、缩放和尺寸。
普通网页只允许 http/https，另支持 `ly-preview` 与用户新标签页的 `about:blank`。
本地 HTML（`file://`、绝对路径，`browser_open` 另收工作区相对路径）不交给页面加载：主进程把这一个文件
拷进预览目录，再按 `ly-preview` 打开（`electron/local-page.ts`）。不用起服务，会话在页面就在。同一个文件
只有一份副本、地址固定，改了以后再打开一次就是新内容；只拷这一个文件。Agent 传的路径与 `read` 走同一道
读取判定。

`browser_open` 打开页面时展开侧栏、切到那个标签（只在显示该会话的那一屏）；之后的点击、输入、切标签
不再把面板拉出来。对话里每次打开留一行浏览器卡片：标题、地址和「打开」，没有缩略图——网页嵌在对话里是
`preview` 的事，两者长得一样就分不清。同一轮里同一个页面（地址去掉 `?`、`#`）只留最后一行。

对话里的预览以工具行样式显示图标、标题和尾部箭头，点击这一行展开或收起。内容与工具详情一样向右缩进 22px、
顶部留 6px，复用 `Collapse` 的展开收起动画。折叠期间保留 iframe 的布局和页内操作状态，列宽变化时仍更新高度；
再次展开保留原来的高度模式。折叠状态只保留在当前挂载的预览中，不写入会话。

Agent 的点击、悬停、输入与按键走 Chromium 原生输入。选择器来自当前页面；定位考虑页面缩放与
视口适配比例，光标在隔离 JavaScript world 的 closed shadow 中绘制。光标移动完成后再点击，
通过渲染帧确认焦点，遵循减少动画设置。浏览器技能随桌面构建分发并注册到现有 SkillRegistry。
页面内容和工具返回的网页信息是待检查数据，不能成为 Agent 的新指令。

工具栏提供标签页、历史、地址、收藏、元素检查、区域检查、原生 Chromium DevTools、缩放与
视口预设及自定义尺寸。缩放允许 25%–300%，视口限制为 240–3840 × 240–2160；超过面板时
按比例缩小呈现，工具返回实际 `innerWidth/innerHeight/devicePixelRatio`。页面缩放会改变
可用 CSS 像素尺寸。Chromium 共享同源缩放，切回标签时恢复该标签选择的缩放。

地址栏同时是搜索框。判定在 `shared/browser.ts` 的 `browserAddressLike`：带 `//` 的 scheme、
`host:port`、字面 IP、以及末段是两个以上字母的主机名算地址，其余算搜索词——包括 `3.14` 这种
只是长得像主机名的东西，以及 `javascript:`、`data:` 这类没有 `//` 的 scheme，后者只被搜索、
永不导航。搜索引擎在设置里选（必应、Google、百度、DuckDuckGo，或填一个含 `%s` 的自定义地址），
默认必应；自定义地址必须能容下搜索词且是 http/https，否则设置页当场拒收并说明原因。地址栏下拉
给出将要执行的那一件事和匹配的书签，↑↓ 选择、回车执行。转换只发生在渲染层，IPC 仍只接受地址。

检查模式拦截页面点击，返回真实 screenshot、selector、HTML、样式和边界尺寸。退出、导航、
关闭清理监听器。添加到对话时附带图片和修改要求，附件绑定当前草稿，切换会话不能串入另一草稿。
书签、搜索引擎、新页默认缩放和链接默认打开位置保存到设置；链接可选系统默认浏览器或内置浏览器。

## 会话运行服务

core 的 BackgroundJobs 持有实际 SandboxProcess，记录 UUID、PID、命令、状态和退出时间。
停止只接受该会话自己持有的句柄，不能传入任意 PID；进程结束后即使操作系统复用 PID 也不再操作。
POSIX 结束进程组，普通停止使用 `SIGTERM`，强制结束使用 `SIGKILL`。Windows 不提供 POSIX
`SIGTERM`，普通和强制停止都使用 `taskkill /PID /T /F` 终止该任务的进程树；不带 `/F` 的
窗口关闭请求无法停止没有窗口的控制台子进程。停止失败保留错误，只有真实退出才记录结束时间。
信号退出保留空 exitCode，用 finishedAt 表示结束，不能写成 exit 0。

主进程通过系统进程树和 TCP listener 关联任务：macOS 为 ps/lsof，Linux 为 ps/ss，Windows
为 PowerShell 的 Get-CimInstance/Get-NetTCPConnection。只展示该任务及其子进程的真实监听
地址与端口；输出中的 URL 必须匹配监听端口和本机地址，没有 URL 时用有界 HTTP HEAD 探测。
查询失败会显示原因，不伪造端口。每项最多展示 16 个 listener，面板最多查询最近 30 个任务。

任务面板在待办列表上方展示运行服务，包含 PID、IP:port、复制、打开和停止操作。可见时约每
2 秒查询，切换保留上次快照。普通停止和强制结束按上述平台语义执行，结束后移除运行项。应用重启不把历史 PID
当作可操作进程。只有经本会话 background bash 启动的进程在此管理，外部自行启动的服务不归属。

## 授权与命令联网

审批时选择的「始终允许」写入全局 `~/.plume/settings.json` 的 `alwaysAllow`。
管理这些记录时直接编辑配置文件，重启应用后按新列表加载。

命令在所有文件权限模式下都可以联网。文件沙箱继续按权限模式限制写入，不再提供断网策略；
旧配置里的 `denyCommandNetwork` 和 `allowedHosts` 在加载时丢弃。网页抓取与命令一样支持内外网，
不再根据公网、私有网段、回环或链路本地地址拒绝请求，也不需要内网白名单。URL 格式与协议校验、
禁止 URL 内携带账号密码、同源重定向、超时、内容类型及响应大小限制继续保留。

## 工程交付记录

### 文件编辑约束

`read`、`edit`、`write` 用规范路径关联文件。写到项目外要经过审批（卡片上是完整路径和 diff，
自动模式下标「写入当前项目之外的位置」）；`~/.plume` 除 scratch 外不可写；项目或 scratch 里指向外面的
符号链接不能拿来写，要按它指向的真实路径写，审批卡才写得出改的是哪里。
读取项目外的符号链接目标仍需经过读取授权。`ls`、`grep`、`glob`、`lsp` 和 `bash` 命令行里的路径同样先解析
符号链接再判定（`read-access.ts` 的 `resolveForReading`），工作区里指向外面的链接按它指向的位置询问。
文本读取记录完整内容的 SHA-256 和实际显示的行范围。编辑前文件必须仍是读到的那个版本，否则拒绝、
要求重读。图片与文档抽取结果不算可编辑的原始文本。

`edit` 按原文替换（`old_string` → `new_string`），不按行号：换一个词只给那个词前后几个字，不用重打
整行。为什么从行号补丁换过来见 [ADR-0046](../adr/0046-edit-by-text.md)。`old_string` 必须精确、唯一，
重叠命中也算歧义；显式 `replace_all` 按不重叠命中逐个替换。`new_string` 按字面写入 `$` 等字符。
几处互不相干的改动在同一条回复里发几次 `edit`，按顺序执行，后一次看到的是前一次改完的文件。

已读范围跟着行走：编辑把行挪到哪，「看过」就跟到哪；编辑写进去的行算看过，结果里回显的改动处也算。
`old_string` 落在没读过的地方（折叠掉的函数体、分页没读到的部分）时，拒绝并在报错里附上这几行
（至多 40 行、单行不超长），同时记为已看过：模型核对后原样重发即可，不用再读一轮。

CRLF 文件里 `old_string`/`new_string` 用 LF 写也能命中，写回保留 CRLF、BOM 和文件末尾有没有换行；
换行混用的文件不做规范化。

同一进程中的 `edit` 与 `write` 共用文件队列，路径和 inode 都参与排队，硬链接也不会并发写入。
审批后重新检查内容、路径和文件身份，已有文件使用固定句柄写入以保留 inode、权限和硬链接；
新文件排他创建。只允许普通 UTF-8 文本文件。队列不约束 shell 或其他进程；检查与写入之间仍有
外部竞争窗口，截断后写入也不是原子操作，写入中断会明确提示文件可能不完整、需要重读。

差异预览先去掉公共前后缀，再按编辑距离搜索，避免两处相隔很远的修改分配整个文件的二维矩阵。
搜索超过预算时显示中间块的完整删除与新增，内容不丢失，但这时增删统计不保证最小。

回归入口：`packages/core/test/edit-safety.test.ts`、`packages/core/test/diff.test.ts`；真实桌面端
验证运行 `node --experimental-strip-types packages/desktop/e2e/edit-safety-demo.ts`（先 `pnpm build`），
使用临时项目和本地模型协议服务，录制编辑、差异审阅与撤销到桌面 `Plume编辑工具测试` 目录。

### 代码导航（`lsp` 工具）

按文件扩展名路由：TypeScript/JavaScript 走随包的 `tsserver`；Python（basedpyright 或 pyright）、
Go（gopls）、Rust（rust-analyzer）、C/C++（clangd）走标准 LSP（stdio），服务器表在
`core/src/lsp/servers.ts`，加一种语言就是加一行。这些服务器不随包附带，只用本机 PATH（经
`commandEnv`，从图标启动时也能找到 shell 里配的目录）上找得到的；Windows 上按 PATHEXT 找到
npm 装的 `.cmd` 并经 `cmd.exe` 启动，回收时按进程树结束。找不到时退回同语言文件的文本搜索，结果里
写明「这个语言没有可用的语言服务器（需要安装 …）」；`rename` 在没有服务器时照旧拒绝。

每台服务器第一次被问才起，起不来三秒内就先给文本答案，空闲十分钟回收（`lsp/manager.ts`）。
每次提问前从磁盘重读文件，变了就整篇 `didChange`，所以 agent 改过文件后的回答不按旧内容算。
发给服务器的路径换成真实路径、收回来再换回项目根，避免符号链接下的项目（macOS 的 `/var` →
`/private/var`）同一个文件被当成两个。clangd 会在项目里写 `.cache/clangd/index`，这是它自己的行为。

回归入口：`packages/core/test/lsp-stdio.test.ts`（路由、降级提示、URI 与 Windows 路径、分帧）、
`packages/core/test/lsp-stdio-server.test.ts`（对着假服务器走完握手、改文件后重问、诊断、回收）。

### 快照与撤销

write/edit 在变更前保存 before/after 快照，并在批准后重新核对基线，避免覆盖等待期间的修改。
快照按 sessionId 哈希和 UUID 存在私有 `changes` 目录；工具结果只携带变更 ID。foreground bash
在 Git 仓库记录执行前后的工作区差异，基线包含原有未提交和暂存改动，不能把用户原有改动算给本轮。
这些 git 调用在宿主进程里跑，而仓库是沙箱可写的，所以它们不读仓库配置（`host-git.ts`）：除了
`rev-parse` 与 `config --list`，其余在 `~/.plume/git-views` 下临时生成的 `GIT_DIR` 里执行，配置只带
换行转换等白名单数据键，没有 filter/diff 驱动、fsmonitor、钩子和 promisor 远端。沙箱内命令写进
`.git/config` 的程序不会被宿主执行；缺对象时记录失败并提示，不会去拉取。

交付记录从可信 transcript 按回答切分一轮，合并同文件多次修改为净差异。存在文件变化或验证
命令时生成临时 Markdown，区分用户需求、Agent 说明、实际文件差异、命令输出和退出状态。
普通问答不生成工程报告。会话目录清理时同时清理变更快照与报告。

回答下方显示文件列表、语法高亮差异预览、完整审阅、报告入口；服务 URL 只关联本轮实际启动的
后台任务，继续查询到服务监听就绪或退出，不把其他轮的服务附到每个旧回答。报告与当前上下文
记忆文件通过主进程精确路径授权在文件面板只读预览，不开放所在目录或相邻配置文件。

一键撤销要求直接 write/edit 的快照连续、文件仍与最后快照一致、位于当前项目且项目没有运行任务。
用户后续修改会拒绝撤销；新文件可删除回到不存在的状态。命令期间观测的修改可能包含并发写入，
因此展示供审阅，不自动撤销。不会执行整体 Git reset。

记录有明确覆盖边界：没有历史快照的旧会话不能重建逐轮差异；非 Git shell 修改不自动记录；
binary、非普通文件、单文件超过 2 MiB、超过 200 文件或初始脏文件总量超过 16 MiB 会提示未覆盖。
报告中的实际命令证据不是对 Agent 自述的独立背书，不能把“说明中声称测试过”显示成测试通过。

## 输入、截图与轻量信息

文字输入统一经过 NativeField 的 Input/Textarea，保留原生 selection、ref、复制粘贴与撤销。
compositionStart/End、native isComposing、229 和 AltGraph 阻止应用快捷键抢走 IME 候选操作；
不 preventDefault，以保留输入法原生确认行为。WeakSet 同时让 document capture 快捷键看到状态。

截图设置在所有桌面平台可用。关闭截图功能释放全局快捷键，主进程拒绝启动；清空快捷键仅释放
快捷键。启动失败通过调用入口显示，不能捕获错误后返回成功。Windows 截图不再隐藏主窗口；
macOS 仍保留外部截图时避免激活整个应用窗口组的专属处理。

新 profile 默认按最近创建排序，用户明确保存的最近更新排序不改变。侧边栏座右铭已删除，抽屉底部
的设置按钮只写「设置」，不再显示供应商信息。上下文中的项目指令与项目记忆合并为轻量
“记忆文件” disclosure，使用实际来源路径、统一 ChevronRight、ScrollText 和文件预览入口。

## UI 约束

- 行内操作复用 IconButton：小号 22px、标准 26px，图标与文字垂直居中，label 同时提供 tooltip
  和可访问名称。hover 出现的操作预留尺寸，不能让名称、数字或行高变化；键盘聚焦同样可达。
- 常驻文案只解释当前选择，次要说明放 info icon tooltip。钩子、命令和技能候选的操作遵循同一规则。
- 折叠复用 Disclosure，关闭后内容 inert；轻量统计不额外画卡片、背景或分隔线。
- 长单行文本使用 ScrollText 的渐隐与 hover 滚动；列表使用 Scroller 的上下边缘渐隐。
- 过渡复用 motion tokens：quick 150ms、base 220ms、slow 340ms。点击定位不缩放或弹跳，
  hover 与打开关闭的过渡不卸载重建仍需保留的页面。减少动画偏好必须受尊重。

测试入口与运行限制见 [测试](testing.md)。

浏览器空页使用与容器一致的 shell 背景、Globe 空态和聚焦地址栏的入口；地址栏下不额外画分隔线。网页本身的样式由页面决定。

## Git 空状态操作入口

工作区干净时，ChangesView 只展示分支与远端的关系文案；推送、拉取与发布统一由 GitPanel 顶栏
SyncControl 提供。超前、落后、分叉和未发布状态不再在 PanelEmpty 生成第二个同步按钮。
