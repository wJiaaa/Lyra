# 手机端与 plume:// 链接：怎么配对手机，别的应用怎么打开某个会话

手机 App 连的是你自己的电脑：在手机上继续会话、新建会话、查看执行结果、回答授权请求。Agent 和项目始终留在电脑上。发布页只附带 Android 安装包（`Plume-<版本>-arm64-v8a.apk`）。

## 在电脑上打开访问

1. 打开「设置 › 手机连接」，打开「允许手机访问」。
2. 「监听端口」默认 4517，可填 1024–65535。开着访问时改不了端口，要先关掉。
3. 打开后下面出现「配对一台手机」：一个二维码，和「手机从哪里连过来」的地址选择。地址有三类：中转服务器（填了才有，排最前）、本机的局域网地址、`127.0.0.1`（只有这台电脑上的模拟器用得上）。

## 配对

- **扫码**：手机上打开 Plume，点「扫描配对二维码」，对准电脑上的二维码，连上后直接进入会话列表。
- **配对链接**：点「复制配对链接」得到一条 `plume://pair?...` 链接。在装了 Plume 的手机上点开它会直接配对；也可以粘进手机「手动输入」页的地址栏。
- **手动输入**：手机上选「手动输入」，选「直连」或「经中转」，填「桌面地址」（如 `http://192.168.1.20:4517`）或「中转服务器地址」，再填「配对令牌」。令牌在电脑上「配对令牌」那一行，点「显示令牌」或「复制令牌」。
- 二维码、配对链接和令牌都等同于密码，拿到的人可以操作这台电脑上的 Agent，不要截图发给别人。
- 「重置令牌」会换一个新令牌，已连接的手机全部断开，需要重新配对。
- 手机上「设置」里的「断开并忘记这台电脑」会删掉保存的连接。

## 网络：直连还是中转

- 直连要求手机和电脑在同一网络或同一个 VPN 里。从外网访问请用 HTTPS 反向代理或 VPN。
- 不在同一网络时用中转：在「中转服务器」里填中转服务的地址（如 `wss://relay.example.com`）点「保存」，两端都主动连它，隔着路由器也能配对。Plume 不提供云端中转，地址要填你自己部署的 Lyra 中转。
- 中转状态会显示「正在连接中转…」「已连上中转，等手机连进来」「有一部手机正经中转连着」。经中转同一时间只能连一部手机。
- 选了中转地址生成的二维码 / 链接，手机就会经中转连。

## 用链接打开某个会话（macOS）

别的应用或脚本可以让 Plume 打开指定的会话：

```
plume://open-session?id=<会话 id>
```

- 会话 id 在侧栏右键会话 › 复制会话 ID。
- 终端里可以这样试：`open "plume://open-session?id=<会话 id>"`。Plume 没在运行时会先启动，窗口加载完再打开这个会话。
- 只在 macOS 的安装版上有效；Windows、Linux 和开发环境里系统不会把这种链接交给 Plume。
- 只认这一种写法，id 只能是字母、数字、`_`、`-`（最长 64 个字符）。写错了不会报错，什么也不发生。
