# 审批与权限：哪些操作要你点头、三种权限模式、沙箱、项目外的文件

## 三种权限模式

点输入框里的权限按钮选择（「应如何批准 Plume 操作？」），也可以在「设置 › 常规 › 权限」里用「自动审核」「完全访问」两个开关切换。这是全局设置，默认是「帮我批准」。

| 模式 | 什么时候问你 | 命令在什么环境里跑 |
| --- | --- | --- |
| 请求批准 | 每次改文件、写文件、调用 MCP 工具、在内置浏览器里打开网页都问；命令只有只读的（如 `git status`、`ls`、`grep`）不问 | 只读沙箱：命令不能写任何文件 |
| 帮我批准 | 只对检测到的风险操作请求批准（见下文） | 沙箱：只能写当前项目目录和系统临时目录 |
| 完全访问 | 从不问 | 不经过沙箱 |

切到「完全访问」时会先弹「开启完全访问？」确认：开启后 Plume 可以读写这台电脑上任何文件、运行任何命令、访问网络，不再逐项请求批准。

## 审批卡片上的三个按钮

- **允许一次**：只放行这一次。
- **以后不再问**：放行，并记住这一项。记的是完全相同的那条命令、那个文件路径或那个 MCP 工具；读取项目外的目录时记的是那个目录。记录保存在 `~/.plume/settings.json` 的 `alwaysAllow` 列表里，设置页里没有管理入口，要撤销就从这个列表里删掉对应的那行。
- **拒绝**：agent 会收到「用户拒绝了」，通常会换个办法。

审批卡片 5 分钟没人回应，按拒绝处理。agent 用提问卡片问你问题时，等 30 分钟。

## 「帮我批准」下哪些操作算风险

命令默认放行，只有命中「做了就收不回」的规则才问，卡片上会写明原因。主要几类：

- 删除：递归删除目录、强制删除通配匹配的文件、删除根目录或主目录、不可恢复地擦除文件。
- Git：强制推送、`reset --hard` 一类丢弃未提交改动、删除未跟踪的文件、重写提交历史。
- 系统：以管理员身份执行、关机或重启、格式化或分区磁盘、改系统服务 / 定时任务 / 防火墙 / 注册表、修改 shell 启动文件。
- 网络：下载并直接执行脚本、把本机文件上传到网络、发布到公共仓库。
- 密钥：读写 `~/.ssh/id_*`、`~/.aws/credentials`、`~/.gnupg`、`~/.netrc` 等密钥文件。

用 agent 的文件工具写文件时，写在当前项目内不问，写到项目外（系统临时目录除外）要问。

MCP 工具默认每次调用都问。服务器给工具标的「只读」「会删除或覆盖数据」只是它自己的说法：

- 标了会删除或覆盖数据的，一定问，卡片上写着「服务器声明这个工具会删除或覆盖数据」——除非你之前在它的卡片上点过「以后不再问」。
- 标了只读的，只有你信任这台服务器时才不问：在「设置 › 插件 › MCP」里，鼠标移到它的卡片上点滑杆图标（「启动方式与环境变量」），打开「信任它的只读声明」。

MCP 服务器在调用中途弹出的填写表单不是审批，「完全访问」下也会弹，要你自己填，见 `plume://mcp`。

## 沙箱

沙箱只管 agent 运行的命令能写哪里，不限制联网：

- macOS 用系统自带的 Seatbelt，Linux 用 bwrap（不可用时用 Landlock），Windows 用受限令牌。
- 这台机器上拿不到沙箱时，需要沙箱的命令直接拒绝执行，不会悄悄在无保护的情况下跑。
- 命令被沙箱挡住时，agent 可以申请对这一条命令放宽限制（卡片标题是「提权运行：…」），并写明理由。提权一律由你在卡片上批准，「帮我批准」模式也不会自动放行；批准只对这一次调用有效，「以后不再问」也不会记住它。

## 项目外的文件能不能读写

- **读**：当前项目、同一项目里添加的其他文件夹、系统临时目录、已安装的技能、你附加给 agent 的文件、系统工具链目录，直接读，不问。其他位置要你批准。
- **密钥文件**即使在项目里也要批准，而且按单个文件批准，不会连带同目录的其他密钥。
- **写**：「帮我批准」下，文件工具写到项目外要批准；命令则被沙箱限制在项目目录和临时目录内，要写别处得申请提权。「请求批准」下所有写入都要批准。
- 「完全访问」下以上都不问。

`web_search` 和 `web_fetch` 在任何模式下都不需要审批，见「联网搜索」那篇。
