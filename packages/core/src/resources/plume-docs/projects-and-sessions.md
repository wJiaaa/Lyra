# 项目与会话：怎么打开项目、会话存在哪、怎么归档，以及用 @ 引用文件和会话

## 打开项目

- 入口有三个：侧栏「项目」标题右侧的「新建项目」（鼠标移到标题上才出现）；输入框上的项目按钮（「选择项目」）弹出的列表底部的「新建项目」；侧栏顶部放大镜打开的命令面板里搜「新建项目」。
- 弹出「创建项目」：填项目名称（留空就用文件夹名），在「源文件夹」下点「添加」选一个目录，再点「创建」。
- 第一个文件夹是「主文件夹」，会话在这里运行。还可以再加几个文件夹，它们属于同一个项目：文件树里能看到，`@` 也能引用到。
- 切换项目：点输入框上的项目按钮，在「切换项目」列表里选；或在侧栏项目上右键 › 在这里新建会话。
- 不想放进任何项目：项目列表底部选「不在项目中工作」，或点侧栏「聊天」标题旁的「新对话（不在项目中）」。这类会话各自在 `~/.plume/workspaces/` 下有一个自己的目录，没有 Git 面板和文件树。

## 改项目、移除项目

在侧栏项目上右键（或点项目右侧的「项目操作」）：

- **编辑项目**：改名字、增删源文件夹。主文件夹在这里换不了；想让某个会话换到别的项目，用会话右键 › 项目。
- **归档聊天**：把这个项目下的会话全部归档。
- **移除**：项目从列表里去掉，它的聊天一并归档，之后能在「设置 › 已归档的聊天」里找回。磁盘上的目录和文件都不动；置顶、改过的名字会丢。
- 项目文件夹被删掉或挪走后，会提示「文件夹已经不在了：<路径>。可以在项目菜单里把它从列表移除。」

## 会话

- 侧栏是一张列表：置顶的在最上，然后是「项目」，不属于任何项目的会话在「聊天」里。排序和拖动规则见侧栏的「列表设置」。
- 鼠标移到会话上会出现「置顶会话」「归档会话」按钮。右键会话有：置顶、重命名、归档、标记为未读、项目（移到别的项目）、打开方式（分屏 / 新窗口）、复制工作目录、导出原始记录、复制会话 ID、查看调用轨迹。
- 移到别的项目只能在会话没在运行时做，否则提示「这条对话正在运行，先让它停下来再移动。」
- 标题：先用第一条消息的简短标题；正文超过 12 个字时，后台会再请模型起一个标题。关掉在「设置 › 常规 › 智能标题总结」，标题用的模型在「设置 › 智能体」里选。

## 会话存在哪

- 所有会话记录在 `~/.plume/sessions/sessions.db` 这一个文件里。
- 「设置 › 存储」显示它占了多大，可以按会话最后活动的时间清掉一段。清除会连对话记录一起删掉，无法撤销。
- 单个会话的原始记录：右键会话 › 导出原始记录，导出后文件路径会复制到剪贴板。

## 归档

- 归档只是把会话移出侧栏，记录和用量都还在。
- 归档：鼠标移到会话上点归档图标，或右键会话 › 归档；命令面板里有「归档当前会话」；项目右键 › 归档聊天会归档整个项目的会话。
- 找回：「设置 › 已归档的聊天」，按项目分组，可以搜索。点「取消归档」放回原来的项目下。
- 在这一页删除才是真删：单个删除或「全部删除」都无法恢复。
- 「设置 › 常规 › 归档后收起项目」打开后，项目下的会话全部归档时，项目也从列表里收起。

## 用 @ 引用

在输入框里打 `@`，弹出的菜单分几组，继续打字可以筛选：

- **文件和文件夹**：当前项目里的路径，多个源文件夹时每行注明来自哪个。选中后插入成 `@"路径"`。另有「选择文件」「选择文件夹」，用系统对话框选任意位置的一个。
- **会话**：历史会话，可按标题或会话 ID 搜。选中后这条消息会带上那段对话的引用，Plume 需要时去读它的记录，当作参考材料。
- **智能体**：`@名字` 把事交给这个子智能体，详见 `plume://subagents`。
- **插件与技能**：插入 `/skill:技能名`，点名用这个技能。
- `@compact`：压缩上下文，等同 `/compact`。
