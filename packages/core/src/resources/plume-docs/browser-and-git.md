# 内置浏览器和 Git 面板：在哪打开、各能做什么

两个都是对话旁边的面板。打开方式：

- 窗口顶部工具栏的快捷按钮（侧边聊天、终端、浏览器、Git 各一个），或旁边「⋮」打开的「面板」菜单。
- 快捷键：浏览器 ⌘T，Git ⌘⇧R（Windows 上用 Ctrl 代替 ⌘）。
- Git 面板要先打开一个项目；不在项目里的会话没有这个面板。

## 浏览器

- 顶上一排：后退、前进、刷新、地址栏。地址栏里输入的不是网址时，交给搜索引擎搜；也会列出名字匹配的书签。
- 地址栏右侧「…」是浏览器菜单：新标签页、关闭标签页、收藏网页 / 取消收藏网页、书签、检查元素、框选区域、开发者工具、缩放（25%–300%）、视口尺寸。
- 视口尺寸有预设：自适应窗口、手机 · 390 × 844、平板 · 768 × 1024、桌面 · 1440 × 900，也能手填宽高。
- **把页面上的一块交给 Agent**：菜单里选「检查元素」或「框选区域」，在页面上选中后会弹出一个小输入框「希望 Agent 如何修改这个区域？」。写一句要求点「添加到对话」，这块区域的截图、网址、选择器、样式和 HTML 会放进主输入框，再由你按发送。不写要求就默认是「请检查这个页面区域。」按 Esc 退出选取。
- Agent 也能操作同一个页面，操作时显示实时光标。每个会话的标签页各自独立。
- 开发者工具包含 Elements、Styles、Console 和 Network。

相关设置在「设置 › 浏览器」：

- **默认打开链接**：系统浏览器（默认）或内置浏览器。
- **地址栏搜索**：必应（默认）、Google、百度、DuckDuckGo，或选「自定义」，填一个把搜索词换成 `%s` 的地址。
- **新页面缩放**：75%–200%。
- **书签**：列出收藏过的网页，可以打开或删除。

## Git 面板

面板上方是仓库选择和同步按钮，下面分四页：改动、历史、分支、流水线。

- **仓库**：项目文件夹里有几个仓库就列几个（往下找两层）。一个仓库的工作树挂在它下面，可以切过去看。
- **改动**：分「已暂存」「未暂存」，能暂存、取消暂存、放弃改动，可切换树状 / 扁平列表。放弃改动会让文件回到上次提交的样子，没提交过的内容找不回来。
- **提交**：改动页底部的提交框里写提交信息再点「提交」；旁边的按钮「用当前模型写提交说明」可以代写，提交说明的语言也能在那里切换。
- **推送**：点「推送」会弹出提交并推送的小窗：提交信息留空会自动生成；勾「包含未暂存的更改」连未暂存的一起提交；「提交到」可以选新建一个分支；最后点「提交并推送」。从没推送过的分支，这个按钮叫「发布」。
- **同步**：另有「拉取」和「刷新（询问远端）」。正在进行的拉取 / 推送 / 刷新，再点一下同一个按钮就取消。
- **历史**：提交记录和每次提交改了哪些文件。
- **分支**：列出本地和远程分支；新建分支、切换、删除，两个分支可以对比差异。删除只删本地这一份。
- **流水线**：GitHub Actions 的运行记录。需要在「设置 › 代码托管」登录对应的 GitHub 账号，否则读不到。
- 目录不是 Git 仓库时显示「未检测到 Git 仓库」，可以点「初始化仓库」，或点「让 Agent 处理」。仓库读不出来时显示「Git 仓库异常」，可以点「诊断并修复」交给 Agent。
- 暂存、提交、推送、切换分支这类会改仓库的操作，只对已打开项目里的目录生效；不在项目里会提示「该目录不在已打开的项目内」，见 `plume://troubleshooting`。
