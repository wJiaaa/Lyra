# 定时任务：怎么建、什么时候跑、跑出来的结果在哪

定时任务按时间自动开一个新会话，把写好的提示词发出去。适合「每天早上审一遍未提交的改动」「每小时跑一次测试并报告失败」这类事。

## 在哪

- 侧栏的「定时任务」，或菜单栏 / 托盘图标菜单里的「定时任务」。
- 侧栏这一项旁边的数字是运行失败、还没看过的任务数。

## 新建

1. 先切到要让任务在里面跑的项目，再在「定时任务」页点「新建」。任务的工作目录就是这时打开的项目，之后在卡片上只能看、不能改；没打开项目时显示「（未设置工作区）」。
2. 新任务默认是**停用**的，名字叫「新任务」，带一句示例提示词，时间是每天 09:00。
3. 在卡片上改名字和提示词。
4. 选时间：
   - 「每天」+「每天运行时间」，比如 09:00。
   - 「每隔」+ 分钟数，1 到 1440 分钟。
5. 打开卡片顶部那一行的开关，任务才会开始按时运行。

## 什么时候跑

- 只在 Plume 开着的时候跑。Plume 每分钟检查一次，刚启动约 5 秒后也会检查一次。
- **每天**：当天到了设定时间、且今天还没跑过就跑一次。电脑在那个时间点没开 Plume 的话，当天之后打开 Plume 时会补跑一次；错过的前几天不会补。
- **每隔 N 分钟**：从上次运行算起满 N 分钟就跑。刚打开开关、从没跑过的任务会在一分钟内跑第一次。
- 同一个任务上一次还在启动时不会再开第二个。
- 每次都是全新的会话，不接着上一次的对话。用的模型是「新会话的默认模型」（在模型菜单里「设为新会话的默认模型」，或「设置 › 模型设置」里「设为默认模型」）。

## 立即运行、查看结果

- 卡片上的「立即运行一次」会马上跑一次。它只对**已开启**的任务有效；「每天」类型的任务在当天设定时间之前点也不会跑。
- 运行中的任务，卡片上显示「正在执行」或「等待你的批准」——需要批准时去那个会话里点。
- 卡片底部显示「上次运行」「下次运行」，点「打开上次会话」看结果。
- 失败时卡片上显示「失败：原因」。输入框上方也会出现一行「定时任务「名字」失败：…」或「定时任务「名字」无法启动：…」，点「查看」跳到那张卡片，点「知道了」收起；侧栏「定时任务」旁的数字同时清零。
- 失败也算跑过一次，不会每分钟重试。

## 删除

点卡片上的删除按钮，确认后这条任务不再运行，提示词和时间设置一起删掉；已经跑出来的会话留着。
