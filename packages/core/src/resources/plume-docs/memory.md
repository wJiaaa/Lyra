# 项目说明与记忆：Plume 自动读哪些说明文件，记忆存在哪、怎么查看和删除

## 自动读取的项目说明文件

每一轮开始前，Plume 会从当前工作目录往上找说明文件，放进给模型的提示里：

- 文件名：`PLUME.md`、`AGENTS.md`、`CLAUDE.md`，以及 `.agent/AGENTS.md`、`.agents/AGENTS.md`。
- 范围：从工作目录一路往上到 git 仓库根（最近一个含 `.git` 的上级目录），最多 10 层。不在 git 仓库里时只看工作目录这一层。仓库根以上（比如家目录）的文件不读。
- **同一层只用一份**，优先级：`PLUME.md` > `AGENTS.md` > `CLAUDE.md` > `.agent/AGENTS.md` > `.agents/AGENTS.md`。同一个目录里同时有 `AGENTS.md` 和 `CLAUDE.md` 时，`CLAUDE.md` 不生效。
- **不同层都生效**：仓库根的先放、离工作目录近的后放。子目录的说明更具体，冲突时以它为准。
- 空文件跳过；单个文件超过 100 KiB 只放前 100 KiB，并提示模型去读全文。
- 改了说明文件，下一轮就会读到，不用重开会话。
- `~/.claude/CLAUDE.md` 这类用户级说明文件不读。对所有项目生效的规则写在「设置 › 个性化」的「自定义指令」里，点「保存」。

## 两种记忆

记忆的开关和内容都在「设置 › 个性化」的「记忆」一节。

### 用户记忆

- 你自己写的跨项目偏好，存在 `~/.plume/memory.json`。
- 只能手动添加：在「手动添加一条用户记忆…」输入框里写一条，点添加。模型不会自己往这里写。
- 「用户记忆」开关打开时，每个会话都会带上这些条目。开关关掉时列表也不显示。
- 每条右侧有删除按钮；「清除所有记忆」会删掉全部用户记忆，不可撤销，不影响项目记忆。

### 项目记忆

只对一个项目生效，存在 `~/.plume/projects/<项目编号>/memory/` 下，有两份：

- `learned.md`：模型用 `learn` 工具记下的教训，比如你纠正过、以后还会用到的约定。对话里模型只能往这里写记忆，所以让它「记住」什么，记下的只对当前项目有效。相似的条目会合并成一条，最多保留 100 条，每条最长 2000 个字符；像 `sk-…`、`ghp_…` 这样的凭证会被替换掉。新记下的从**下一个会话**起生效。这个文件可以直接手改，一行 `- ` 开头就是一条。
- `MEMORY.md`：「自动沉淀项目记忆」写的。打开后，空闲 5 分钟时读这个项目 12 小时前到 30 天内、至少 6 条消息的会话（最多 40 个），交给模型总结。会把对话内容发给你配置的模型，**默认关闭**，每天最多一次。用哪个模型在「设置 › 智能体」的「记忆整理模型」里选，没选就用默认模型。

「项目记忆」开关关掉后，既不读也不记，已有的内容保留。

## 查看和删除项目记忆

「设置 › 个性化 › 记忆」下方「项目记住的」，旁边的下拉选项目：

- 每条教训显示写下的时间和最后一次被用进提示的时间，右侧按钮删掉这一条。
- 自动沉淀的那一份只能整份丢掉（「丢弃这份抽取出来的记忆」），下次沉淀会重新写。
- 「全部忘掉」删除这个项目的全部记忆，不可撤销。

在设置里删掉的记忆，下一轮就不再带上。直接改文件的，要到新会话或对话被压缩后才会读进来。
