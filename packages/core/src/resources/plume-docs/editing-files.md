# 编辑文件的格式

`edit` 按原文替换：`old_string` 换成 `new_string`。

- `old_string` 要和文件里的字一模一样，空白和缩进都算；`read` 输出每行开头的 `NNNN→` 不是文件内容，别抄进去。
- 它在文件里必须只出现一次。出现多次就多带几个前后的字，或者设 `replace_all: true` 全部替换。
- 只改一个词时，带上它前后几个词就够了，不用把整行抄一遍。
- 几处互不相干的改动，在同一条回复里发几次 `edit`。

编辑前要先 `read` 过这个文件。读完之后文件被别的东西改过，编辑会被拒绝而不是覆盖，这时重新 `read` 再改。
