# 斜杠命令：有哪些、各做什么，怎么写自己的命令

在输入框行首敲 `/` 会弹出命令菜单，分「命令」「自定义命令」「技能」「MCP 提示词」四组，每行右侧注明来源（内置、项目、个人、Claude · 项目、Claude · 个人；插件里的技能写插件名，MCP 提示词写服务器在设置里的名字）。继续打字会按名字筛选，描述里的字也能搜到。

## 内置命令

| 命令 | 做什么 | 参数 |
| --- | --- | --- |
| `/compact` | 把之前的对话压缩成摘要，腾出上下文。也可以写成 `@compact` | 可选：希望摘要保留的内容 |
| `/clear` | 开一个新对话 | 不接收参数 |
| `/commands` | 打开「设置 › 命令」，管理或新建命令 | 不接收参数 |
| `/btw` | 另开一格侧边聊天问这句话，当前对话里不留任何东西，也不打断正在跑的这一轮。只打 `/btw` 就只打开侧边聊天 | 要问的话 |
| `/plan` | 切换计划模式，详见 `plume://plan-mode` | 可选：要规划的事 |
| `/goal` | 定一个持续目标；留空则取消，详见 `plume://goal` | 目标，或留空取消 |

限制：

- `/compact`、`/clear`、`/commands`、`/goal` 和不带话的 `/plan` 不接收附件，带了会提示先移除；`/btw` 和带着话的 `/plan` 会把附件跟这句话一起发出。
- `/clear`、`/commands` 后面写了参数会被拒绝，输入内容保留。
- `/compact`、`/btw`、`/plan`、`/goal` 需要已经开始的对话；空白新对话里先发一句话。
- 内置命令的名字永远优先：自己写一个叫 `compact` 的命令不会生效。

## 技能也能当命令用

已安装的技能出现在菜单的「技能」组里，`/技能名 这次要做的事` 会让 Plume 按那个技能来做。插件里的技能写成 `/插件名:技能名`。在句子中间写 `/skill:技能名` 也能点名一个技能，比如「帮我 /skill:pdf 处理一下这个文件」。

菜单里找不到的 `/xxx` 不报错，按原样当普通文字发出去（所以路径照常能打）。

## MCP 提示词

已连上的 MCP 服务器如果带提示词，会列在「MCP 提示词」组里，名字是 `/mcp__<服务 id>__<提示词名>`（命名规则和 MCP 工具一样，见 `plume://mcp`）。选中后发出去的是服务器展开的那段话，不是命令本身；附件照常一起发。空白新对话里也能用。

- 菜单里名字后的灰字是参数：`<名字>` 必填，`[名字]` 可选。
- 只有一个参数时，命令后面整段就是它的值。多个参数时按顺序用空格隔开（带空格的用引号括起来），也可以写 `名字=值` 指定。
- 缺了必填参数不会发出去，提示「/… 还缺参数：…。写法：…」，输入内容保留；服务器取不出来时提示「取不到 MCP 提示词 /…：原因」。

## 自定义命令

一条命令就是一个 Markdown 文件：正文是要发给 Plume 的指令，敲 `/文件名` 时发出去的是正文。放在这四个目录之一（可以建一层子目录分组，`git/commit.md` 就是 `/git:commit`）：

- `<项目>/.plume/commands/` 跟着仓库走，团队里每个人都能用
- `~/.plume/commands/` 你自己的，所有项目都能用
- `<项目>/.claude/commands/`、`~/.claude/commands/` Claude Code 的命令目录，也会读取

同名时按上面的顺序，靠前的生效；被盖住的那个文件会出现在「设置 › 命令」顶部的提示里，写明是被哪个文件盖住的。

最方便的建法：「设置 › 命令」，顶部选「用户」或某个项目，点「新建」，输入命令名（小写字母、数字和连字符，例如 `review-diff`），点「创建并编辑」。Plume 会生成一份带示例的文件，并用系统默认程序打开。页面上也可以打开命令目录、删除命令；文件写错时会在顶部提示哪个文件出了什么问题。

文件格式：

```markdown
---
description: 审一下当前的 diff
argument-hint: <要重点看的目录>
---
检查当前未提交的改动，重点看 $ARGUMENTS，只报真实的缺陷。
```

- `description`：菜单里显示的一句话；不写就用正文第一行。
- `argument-hint`：选中命令后输入框里的灰色提示。
- `$ARGUMENTS` 代表命令后面输入的全部内容，`$1`、`$2` 取第一个、第二个参数（用引号把带空格的词括成一个）。一个占位符都没写时，输入的内容附加在正文末尾。
- `deliver`：可选，决定 Plume 正在干活时这条命令怎么送出。`prompt`（默认）和 `followUp` 排到当前这一轮之后；`steer` 直接插进正在跑的这一轮，适合「只看 src/」这类纠偏。空闲时三者一样。
- `name`：可选，覆盖由文件名得到的命令名。

每次发送都会重新读取命令文件，在别的编辑器里改完不用重启。只敲命令的最后一段也能找到，比如 `/commit` 能找到 `git:commit`，前提是只有一条命令以 `commit` 结尾。
