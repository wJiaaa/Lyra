# 联网搜索：web_search 用的哪个服务、怎么配置、没配置时会怎样

## web_search 用的是哪个服务

`web_search` 不绑定某一家，用的是「设置 › 网页搜索」里选中的那个。可选五个：

| 服务 | 要不要 key | 说明 |
| --- | --- | --- |
| Tavily | 要，每月 1000 次免费 | 为 agent 设计，会连带返回一段总结 |
| Brave Search | 要，每月 2000 次免费 | 独立索引，免费额度最大 |
| Exa | 要，有免费额度 | 语义检索，找概念和相似内容更强 |
| DuckDuckGo 速答 | 不要 | 官方接口、不限流，但只有百科式答案，不是网页结果列表，基本只对英文词条有效 |
| DuckDuckGo | 不要 | 抓它的无脚本网页，经常被限流，拿不到结果多半是对方在挡 |

没在页面上选过时，按下面的顺序自动决定：

1. 只有一家填了 key → 用那一家。
2. 填了两家及以上的 key 却没选 → 搜索失败，提示「有多个可用的搜索提供方，请在设置里指定用哪个」。
3. 一个 key 都没填 → 用「DuckDuckGo 速答」。

所以**全新安装、什么都没配时，web_search 用的是 DuckDuckGo 速答**：中文提问多半搜不到东西。中文搜索想好用，要填一个 key。

## 怎么配置

1. 打开「设置 › 网页搜索」。
2. 在「API key」里粘贴对应服务的 key（每项旁边有「申请」链接）。填好后，「用哪一个」列表里那一项显示「已填 key」。
3. 在「用哪一个」里点选要用的服务；再点一次已选中的那项会取消选择，回到自动决定。

改动立即生效，不用重启。选了一个要 key 但没填 key 的服务，搜索会失败并提示「还不能用（多半是没填 key）」。

搜索服务的 key 保存在 `~/.plume/settings.json` 的 `searchApiKeys` 里，选中的服务记在 `searchProvider`（值是 `tavily`、`brave`、`exa`、`ddg-instant`、`duckduckgo` 之一）。注意：这些 key 不像模型供应商的 API Key 那样另行加密存放。

## 每次搜索的行为

- 每次最多返回 8 条结果（标题、链接、摘要）；Tavily 还会附一段总结。条数不能调。
- 30 秒没有响应算超时。
- 搜索不需要审批：它只把查询词发给选中的服务。结果按不可信内容处理，agent 不会把搜到的文字当成给它的指令。

## web_fetch：读取一个网页

`web_fetch` 不经过任何搜索服务，也没有设置项：它直接从你这台电脑请求那个网址，把页面转成文字给 agent。

- 不需要审批，公网、内网、本机地址都能读。
- 只支持 http / https；网址里带账号密码的会被拒绝。
- 只读文本类内容（HTML、纯文本、JSON、XML），图片、PDF 等二进制会被拒绝。
- 响应超过 2 MB 会中断；正文太长会截断。
- 最多跟随 3 次跳转，而且只跟同一站点内的跳转；跳到别的域名时会停下，agent 需要显式再请求新地址。
- 每一跳 30 秒超时。

想让 agent 在网页上点击、输入，用的是内置浏览器，不是这两个工具。
