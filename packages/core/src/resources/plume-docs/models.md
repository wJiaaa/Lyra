# 模型与供应商：在哪添加 API key、怎么切模型和思考等级、配置存在哪

## 添加供应商

1. 打开侧边栏「设置 › 模型设置」，点「添加供应商」（一个都没有时是「添加第一个供应商」）。
2. 在「连接」里填三项：
   - **Base URL**：服务地址，例如 `https://api.example.com/v1`。
   - **API 格式**：Responses、Chat Completions、Messages 三选一。OpenAI 官方用 Responses，Anthropic 用 Messages，其他兼容 OpenAI 的服务一般是 Chat Completions。Plume 只支持这三种。
   - **API Key**：填好后点旁边的「测试」，失败时原因显示在输入框下方。
3. 加模型：点「拉取模型」从当前 Base URL 取模型列表，在「拉取并选择模型」里勾选后点「导入所选」；也可以点「添加模型」手动填「模型 ID」（发给供应商的实际模型名）。
4. 第一个加进来的模型会自动成为新会话的默认模型。

供应商可以重命名、禁用、删除；删除会把它的地址、密钥和下面的模型一起删掉。模型设置页还能把供应商导出为 JSON 文件或从 JSON 导入——导出的文件里带着明文 API Key，不要提交进仓库或发到聊天里。

## 模型参数从哪来：模型目录

- 导入或添加模型时，Plume 从模型目录里查这个模型的上下文窗口、最大输出、是否支持思考 / 图片 / 工具调用、推理档位和参考价格，一次性填进去。之后在「编辑模型」里可以随便改，也可以点「从模型目录填入」重新搜索。
- 目录里查不到的模型按默认值填：上下文窗口 200K、最大输出 32K，思考、图片、工具调用全开。
- 目录来自 pi.dev 的公开模型目录。安装包里带一份快照，离线也能用；Plume 运行时每小时检查一次更新，缓存在 `~/.plume/model-catalog.json`。模型设置页顶部显示目录来源、更新时间和模型数，点「立即更新」可手动拉取。
- 目录只是参考：目录更新不会改动已经配好的模型，发给供应商的模型 ID 也从不改写。
- 上下文窗口决定自动压缩什么时候触发，填得比实际大或小都会让压缩时机不对。

## 切换模型

- 点输入框里的模型按钮打开「选择模型」，可以搜索模型或供应商，也可以「收藏」常用的，收藏的排在最前。
- 在已有对话里选模型只改这个对话。要改新会话的默认模型，点那一行的「设为新会话的默认模型」；在还没发过消息的新对话里选，选中的就直接成为默认模型。
- 对话已经有记录时中途换模型，会先确认「确定要中途切换模型吗？」：之前的推理内容不能跨模型沿用，提示词缓存也会失效，第一轮更慢、更费 token。
- 一轮还在跑时换模型，从下一次请求起就用新模型。
- 子智能体、侧边聊天、智能标题、会话摘要、记忆整理、图片生成用的模型在「设置 › 智能体」里单独选，默认跟随主会话或默认模型。

## 思考等级（推理强度）

- 输入框里的「推理强度」按钮为当前对话选档。档位有：关、极简、低、中、高、超高、最高、极致，但每个模型只显示它支持的那几档（在「编辑模型 › 推理档位」里勾选）；没设置过的模型默认是关、低、中、高四档。模型不支持思考时显示「不支持」。
- 「选择模型」菜单底部的「关闭思考」开关跳过推理直接作答，只影响当前会话；再关掉就回到上一次的档位。
- 新会话的默认档位在「设置 › 常规 › 默认推理强度」，初始是「中」。在还没发消息的新对话里调档，也会改这个默认值。
- 换到一个没有当前档位的模型时，自动取最接近的一档（先往深找，再往浅找）。
- 供应商对推理档位的支持不一，同一档在不同服务上效果可能不同。

## 配置存在哪

- 主配置是 `~/.plume/settings.json`（设置了环境变量 `PLUME_HOME` 时在那个目录下）。和模型相关的字段：
  - `providers`：供应商列表，每项有 `name`、`baseUrl`、`api`（`openai-responses` / `openai-chat-completions` / `anthropic-messages`）、`enabled`、`models`。
  - `models` 里每项有 `modelId`、`name`、`contextWindow`、`maxOutputTokens`、`supportsThinking`、`supportsImages`、`supportsTools` 等。
  - `defaultModelId`：新会话的默认模型，写成 `供应商id/模型ID`。
  - `thinking`：新会话的默认思考档位，如 `"medium"`。
  - `favoriteModelIds`：收藏的模型。
- **API Key 不在 settings.json 里**：保存时会被移到 `~/.plume/credentials.json`（加密，密钥在同目录的 `vault.key`），settings.json 里对应的 `apiKey` 留空。手动在 settings.json 里写的 `apiKey` 也能用，下次保存设置时会被移走。
- 项目里的 `.plume/config.json` 会进仓库，所以不能放供应商和凭证；写了也会被忽略并提示。
- settings.json 解析失败时，Plume 按默认设置运行（不加载供应商），并提示文件路径和原因；修好后重启即可。
