# 插件与插件市场：怎么安装、装到哪、怎么停用和卸载

在 Plume 里，**插件是一组技能的打包**，不含 MCP 服务。市场里同时列着插件、MCP 服务和技能，三样装法相同，装完去处不同。MCP 的细节见 `plume://mcp`。

## 两个入口

- **侧栏「插件」**：打开插件市场，用来浏览和安装。顶部按「全部」「插件」「MCP」「技能」分类，可以搜索。
- **「设置 › 插件」**：管理已经装上的东西，分「插件」「MCP」「技能」「扩展」四个标签。市场右上角的齿轮（「管理已安装」）也通到这里。

## 安装

在市场里点进一项，点「安装」。市场不做代码审核，装之前可以先看看它的仓库。

装到哪里：

| 装的是 | 位置 |
| --- | --- |
| 插件 | `~/.plume/plugins/<名字>/` |
| MCP 服务 | `~/.plume/mcp/<名字>/`，同时在「设置 › 插件 › MCP」里加一条配置，默认关闭 |
| 技能 | `~/.plume/skills/` |

装的是插件还是 MCP 服务，看包里实际有什么：有 `skills/` 就是插件；只有 `.mcp.json` 就是 MCP 服务。

装好的插件从下一个会话起生效：它带的技能出现在 `/` 菜单的「技能」组里，写成 `/插件名:技能名`（插件名取它的目录名）。

## 自己放一个插件

把目录直接放进 `~/.plume/plugins/`（所有项目可用）或 `<项目>/.plume/plugins/`（只在这个项目可用，会标「项目」）。目录结构：

```
my-plugin/
  .lyra-plugin/plugin.json     名字、描述、图标等（也认 .codex-plugin/plugin.json 或根目录的 plugin.json）
  skills/<技能名>/SKILL.md
```

没有 `plugin.json` 也行，只要有 `skills/` 目录就会当成插件读，名字取目录名。项目里和用户目录里有同名插件时，项目里的生效。

## 停用

「设置 › 插件 › 插件」每一行右侧有开关，关掉后它带的技能不再加载，文件不动。市场详情页上也有同一个开关。已经在进行中的会话可能还带着原来的技能，新开一个会话最稳妥。

在 `settings.json` 里写 `"disabledPlugins": ["*"]` 会一次关掉全部插件；这时把任意一个拨回「开」会解除这条总开关。

## 卸载

「设置 › 插件 › 插件」，行右侧 ⋯ › 「卸载」。它的目录会被删除，随它安装的技能也一起消失，重新安装可以拿回来。

- 项目目录里的插件不能在这里卸载，到项目的 `.plume/plugins/` 里删掉目录。
- MCP 服务在「MCP」标签的卡片 ⋯ 里卸载，会连同它在设置里的配置一起清掉。

## 更新与插件来源

- 默认自动更新。市场右上角的 ⋯，或「设置 › 插件」搜索框旁的 ⋯ 里，「自动更新」可以关掉；有新版本时会出现「全部更新」，单个插件行上有「更新」。
- 市场右上角 ⋯ › 「插件来源…」可以添加别的市场，地址必须以 `https://` 开头。
