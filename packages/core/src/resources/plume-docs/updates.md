# 应用更新：怎么检查、怎么装、从哪手动下载

## 检查

- Plume 启动时检查一次，之后按「设置 › 关于 › 自动检查更新」的频率定时检查：每 1 / 4 / 6（默认）/ 8 / 12 / 24 小时。
- 手动检查：「设置 › 关于」点「检查更新」；或菜单栏 / 托盘图标菜单里的「检查更新…」，它会打开同一页。
- 「设置 › 关于」会显示当前版本、发布日期和这个版本的更新内容。结果有三种：「已是最新版本」；「没能连上 GitHub，稍后再试」（这时并不知道有没有新版本）；有新版本时出现「立即更新到 v<版本>」。
- 只提供正式版，草稿和预发布版本不会推送。

## 安装

- 有新版本时，侧栏底部会一直显示「新版本 <版本>」，直到装上为止。点它（或「立即更新到 v<版本>」）打开更新窗口，里面有「这个版本改了什么」。
- 点「下载安装」开始下载。下载中可以「暂停」「继续下载」「取消下载」；关掉窗口不会停止下载，侧栏底部会显示进度。
- 下载完会先和发布页上的校验文件（SHA256SUMS）核对，对不上就删掉、不安装。
- **macOS**：下载完提示「已下载完成。重启 Plume 即可用上新版本，正在进行的对话会中断。」，点「立即重启」。
- **Windows**：下载完会打开安装程序，提示「已下载完成，安装程序已经打开。按它的提示装完，再重新启动 Plume 就是新版本了。」安装窗口不小心关了，点「重新打开安装包」。
- 网络中断时已下好的部分会留着，「继续下载」会接着下。

## 从哪手动下载

- 发布页：<https://github.com/wJiaaa/Plume/releases>。「设置 › 关于」的「版本发布」按钮和更新窗口里的「查看发布页」都通往这里。
- 每个版本附带：Windows x64 安装包，macOS 的 Apple 芯片（arm64）与 Intel（x64）两种 dmg 和 zip，以及校验文件 `SHA256SUMS`。

## 更新失败时

窗口里显示「这次没能写完」和具体原因。常见几种：

- 「连不上下载地址，检查一下网络再试。」——网络问题，点「重试」。
- 「下载中断了。已经下好的部分留着，继续会接着下。」
- 「无法写入更新文件。请检查更新目录的写入权限，并确认文件没有被其他程序占用，再点重试。」
- 「安装包的校验和与发布的不一致……已删除下载的文件。」——重新下载一次；仍然不对就去发布页手动下载。
- 「这个版本没有发布校验文件，无法确认安装包完整。请到发布页手动下载。」
- 「没有找到适用于这台机器的安装包」——发布页上没有这个系统 / 架构的包。
- 「这个副本不是从「应用程序」运行的，无法就地更新」（macOS）——去发布页下载 dmg，把 Plume 拖进「应用程序」再用。
