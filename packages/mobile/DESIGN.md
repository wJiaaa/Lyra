# Plume 手机界面

## 主题
延续 Plume 的安静、工具型界面；独立 React Native 组件，单列导航。结构参考 t3code 与 paseo 的手机端：底色分层、单一强调色、分组卡片、单行工具步骤。

## 色板
与桌面 `tokens.css` 同源。暗色：页面 `#171717`，分组卡片 `#1f1f1f`，卡片 / 用户气泡 `#242424`，浮起 `#2c2c2c`，边线 `#2e2e2e`，正文 `#d4d4d4`，标题 `#f2f2f2`，次级 `#888888`，弱 `#5c5c5c`。操作色 `#339cff`，运行 / 已连接 `#3ecf8e`，等待 / 重连 `#e5a33a`，错误 `#f2555a`。亮色跟随系统；颜色统一在 `src/ui.tsx`。

## 字体
系统字体。页面标题 28/34 粗体，导航标题 17 粗体，正文 16/23，辅助 13–14，分组名 11 大写加字距。代码 Menlo / monospace。

## 形状
分组卡片与底部面板 20–24 圆角，输入框 24，按钮与字段 14–16，用户气泡 20（右下角 6）。触摸控件至少 40 高、主按钮 50 高。

## 层次
靠底色区分层次，不加装饰阴影、渐变或玻璃。只有悬浮在内容上的东西（新会话按钮）带阴影。错误用淡红底，授权与提问用琥珀色标签。

## 组件
- 会话列表：按本地日历日分「今天 / 昨天 / 本周 / 更早」，行首是项目名与时间（运行中换成绿色「进行中」），下面两行标题。长按出归档 / 恢复。新会话是右下角的悬浮按钮，打开底部面板选项目和模型。
- 聊天：用户消息右侧气泡（右上角收小，图片缩略图在上，长按复制），助手回复通栏 Markdown，代码块带语言和复制。工具调用是单行步骤：动词与桌面同一套说法（读取文件、修改文件、执行命令），文件只写文件名，编辑类带 +N −M。点一下从底部升起详情：编辑看着色 diff，命令看终端和退出码，清单看清单。
- 一轮做完，最终回答之前的思考和工具调用折成一行「已工作 1 分 05 秒 · 读取文件 3 个、修改文件 a.ts」，点开挂在左侧细线上展开；回答下面一行是时间、耗时和复制。正在跑的那一轮不折。出错停下的最后一轮给「重试」。
- 授权与提问停靠在输入框上方，答完消失。有计划清单时输入框上方一条「计划 2/5 · 当前项」，做完且任务停了就收起。运行中显示「正在工作 计时」浮条；只有人自己往上翻才停止跟随，离开底部时出现回到底部按钮。
- 输入框是一张卡片：待发的图片在最上，文字居中，下排左侧是加图、模型与思考档位，发送在右。模型不能看图时不给加图。任务运行且框内为空时，发送位变成红色停止。
- 底部面板：遮罩淡入、面板滑入，带把手与关闭按钮；选择即收起。
- 设置：分组列表，危险操作单独一组、红字。

## 使用约束
正文保持可选择；按钮具备无障碍名称与禁用状态。Markdown 链接只打开 HTTP、HTTPS 与邮件地址。手机不展示桌面的 API 密钥或调试请求。

## 响应式
处理系统安全区与键盘避让；横屏和平板内容最多 720 宽，连接页最多 460 宽。长标题截断，正文自然换行，工具输出横向滚动。

## 后续设计约定
新增能力先复用现有运行时与控件；只有手机操作需要时才增加界面。保持聊天为主，不把桌面文件面板、终端和多栏布局搬到小屏。
