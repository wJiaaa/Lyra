# Plume 手机界面

## 主题
安静的工具型界面，单列导航。结构和层次照 t3code、happy、paseo 的手机端：整页一张底，列表和助手回复直接落在底上，只有用户气泡、代码和浮起来的控件有面；分区靠发丝线，不靠灰卡片。

## 色板
颜色统一在 `src/ui.tsx`，亮色跟随系统。暗色：页面 `#0a0a0a`，分组 `#141415`，卡片 / 字段 `#252527`，浮面 `#1c1c1e`，用户气泡 `#212124`，边线 `#27272a`，正文 `#e4e4e7`，标题 `#fafafa`，次级 `#8e8e93`，弱 `#5b5b60`。亮色：页面 `#fcfcfc`，分组 `#f4f4f5`，卡片 / 气泡 `#efeff1`，浮面 `#ffffff`，边线 `#e4e4e7`。操作色与桌面同一个蓝 `#339cff`；进行中用操作色，已连接绿 `#3ecf8e`，需要你处理琥珀 `#f0a83a`，错误 `#f2555a`。

## 字体
系统字体。导航标题 16 半粗，正文 16/23（回复 16/25），列表标题 16 中粗，辅助 13–14，分组名 12 大写加字距。代码 Menlo / monospace，计时与时间用等宽数字。

## 形状
输入框 26，底部面板 28，授权卡 22，分组 14，按钮 14–16，用户气泡 20。标题栏两侧是 40 的圆钮（分组底加细边）。触摸控件至少 40 高、主按钮 50 高。

## 层次
浮在内容上的东西——输入框、授权卡、计划条、回到底部、底部面板——共用 `floating()`：浮面底色、一圈发丝边、一层软投影。其余一律平铺，不加渐变或玻璃。标题栏停在顶部时没有边，内容滚到它底下才出现一道发丝线。

## 组件
- 会话列表：标题栏左边设置、右边新会话，中间是「会话」和电脑的连接状态。按本地日历日分「今天 / 昨天 / 本周 / 更早」；每行首是项目标记（项目名首字的彩色小方块，同一项目同一颜色）、项目名与时间（运行中换成蓝色呼吸点和「进行中」），下面两行标题。行之间是从文字起头的发丝线。长按出归档 / 恢复。空列表给一颗「新会话」按钮。
- 聊天：用户消息右侧气泡（图片缩略图在上，长按复制），助手回复通栏 Markdown，代码块带大写语言名和复制。工具调用是日志式的单行：淡色图标、动词与文件名，编辑类带 +N −M；正在跑的那一步整行呼吸。点一下从底部升起详情：编辑看着色 diff，命令看终端和退出码，清单看清单。
- 一轮做完，最终回答之前的思考和工具调用折成一行「已工作 1 分 05 秒 · 读取文件 3 个、修改文件 a.ts」，下面一道发丝线隔开结论；点开挂在左侧细线上展开。回答下面一行是时间、耗时和复制。正在跑的那一轮不折。出错停下的最后一轮给「重试」。
- 授权与提问是停靠在输入框上方的浮卡，答完消失；选项是浅底色块，选中换强调色淡底加描边。有计划清单时输入框上方一条浮起的「计划 2/5 · 当前项」，做完且任务停了就收起。运行中，消息流的最后一行和桌面的运行行一样：`Thinking… · 12s · 本轮 3.2k tokens`，短语随它在干什么轮换（词表与桌面共用 `@plume/client-runtime/running`），图标位是系统的转圈；等人授权或回答时换成「等待你的批准 / 回答」；回复正文在往外流时这一行收起，字停 2.5 秒或接着调工具时回来；只有人自己往上翻才停止跟随，离开底部时出现回到底部按钮。
- 输入框是一张浮卡：待发的图片在最上，文字居中，下排左侧是加图、模型与思考档位，发送在右。模型不能看图时不给加图。任务运行且框内为空时，发送位变成反色的停止。
- 底部面板：遮罩淡入、面板滑入，带把手与关闭按钮；选择即收起。面板里的选项组用卡片色，比面板亮一档。
- 设置：分组列表，每行一枚有色小方块图标；危险操作单独一组、红字。
- 连接页：头像、名字与一句说明居中；扫码是唯一的主按钮，下面一道「手动输入」分隔线和表单。

## 使用约束
正文保持可选择；按钮具备无障碍名称与禁用状态。界面默认中文，可在设置里切换英文。Markdown 链接只打开 HTTP、HTTPS 与邮件地址。手机不展示桌面的 API 密钥或调试请求。

## 响应式
处理系统安全区与键盘避让；横屏和平板内容最多 720 宽，连接页最多 460 宽。长标题截断，正文自然换行，工具输出横向滚动。

## 后续设计约定
新增能力先复用现有运行时与控件；只有手机操作需要时才增加界面。保持聊天为主，不把桌面文件面板、终端和多栏布局搬到小屏。拿不准某个控件怎么画，先看 t3code / happy / paseo 的手机端怎么做。
